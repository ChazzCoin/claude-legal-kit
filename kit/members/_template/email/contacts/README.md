# contacts/

One file per person (or organization) you correspond with by email.

**Filename:** `<firstname>-<lastname>.md` for people, `<org-slug>.md` for firms or organizations. All lowercase, hyphenated.

**What goes in each file:** who they are, contact info, related matters, tone/preferences, and a running log of every exchange. Use `../_contact-template.md` as a starting point.

The log table at the bottom is what Claude updates as drafts and sends happen. Most recent on top.

# drafts/

One file per email draft. Works in progress live here.

**Filename:** `YYYY-MM-DD-<contact-slug>-<short-topic>.md`
Example: `2026-05-18-jane-doe-smith-status.md`

**Status field** at the top of each draft moves through three values:
- `draft` — being written / iterated on
- `ready` — final, ready for you to paste into Outlook and send
- `sent` — Outlook send confirmed; the file then moves to `../sent/`

Use `../_draft-template.md` as a starting point.

When you paste into Outlook, copy only the body between the `BEGIN BODY` / `END BODY` markers — never the header block or working notes.

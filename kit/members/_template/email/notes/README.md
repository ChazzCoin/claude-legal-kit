# notes/

Anything email-related that isn't a draft and isn't a contact log:

- Reusable phrasings or paragraph templates you find yourself using
- Signature-block variants (formal vs. informal vs. plaintext-only)
- Follow-up reminders ("circle back with Jane on Smith status if no reply by 2026-05-25")
- Observations about a correspondent's patterns
- Anything else worth keeping but not worth its own folder

No required schema. Plain markdown. Date-prefixed filenames help, not required.

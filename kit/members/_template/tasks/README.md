# tasks/

Personal task list. Matter-level deadlines (statutory, court-ordered, discovery responses) live in each matter's `DEADLINES.md`. **This folder is for personal todos** — research items, follow-ups, calls to return, internal commitments.

## Layout

- `TASKS.md` — current open tasks
- `archive/<YYYY-MM>.md` — completed tasks by month (optional, for retrospectives)

## What goes here vs in a matter's DEADLINES.md

| Personal task (here) | Matter deadline (in `DEADLINES.md`) |
|---|---|
| "Call co-counsel re: Smith strategy" | "File motion to dismiss by 5/30" |
| "Read 2nd Cir. opinion on lien priority" | "Discovery responses due 6/15" |
| "Update CLE log for May" | "Mediation 7/10" |

Personal tasks are not part of the matter file. They don't survive a matter closeout — they're for you.

# inbox/

Messages and handoffs from other firm members land here.

## File naming

`<YYYY-MM-DD>-<from>-<topic>.md`

Examples:
- `2026-05-15-alex-smith-medicals-need-review.md`
- `2026-05-16-jane-court-date-moved.md`

## Lifecycle

1. Message lands in `inbox/`
2. Member reads and acts on it
3. If worth keeping for the matter record → move to `firm/matters/<Matter>/08-Notes/`
4. If worth keeping for personal reference → move to `../notes/`
5. Otherwise → delete

`/inbox` skill (when built) will list unread messages and offer to triage.

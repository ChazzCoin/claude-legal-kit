## What this will do once we set it up

- Add new matter deadlines (filing dates, hearings, depositions, trial dates) to each attorney's calendar automatically
- Surface upcoming deadlines at the start of every session so nothing sneaks up
- Block out trial weeks across the firm so other matters don't get scheduled into them
- Coordinate scheduling with opposing counsel (where appropriate — Claude drafts, lawyer sends)

## What we need to decide before turning it on

1. **Calendar service:** Google Calendar, Outlook/365, or Apple
2. **Whose calendars connect?** Each member, individually
3. **What auto-adds vs needs review?** Statutory deadlines (SOL): always auto-add. Hearings from court orders: probably auto-add. Soft internal deadlines: review first.

## Confidentiality notes

- Calendar entries can leak client identity through event titles ("Smith depo at 9am"). Use generic event titles where appropriate ("PI matter — depo," "civil — hearing") and put detail in the description field.

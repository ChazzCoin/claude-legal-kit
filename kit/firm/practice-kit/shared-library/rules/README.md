# rules/

Universal practice rules. Always loaded into Claude's context when working in any matter — the floor everything else builds on.

## Written

- **[privilege.md](privilege.md)** — attorney-client privilege, work product (Hickman, FRCP 26(b)(3)), non-lawyer-staff agent-status, common-interest doctrine, inadvertent-disclosure clawback (FRE 502, and the state-court equivalent)
- **[deadlines.md](deadlines.md)** — the deadline method: the four layers of a deadline, calendaring discipline, malpractice-risk framing. The jurisdiction-specific numbers live in `../jurisdictions/<jurisdiction>/deadlines.md`
- **[conflicts.md](conflicts.md)** — when to run a check, Rule 1.7 / 1.9 / 1.10 framework, imputed conflicts from members' prior practices, waiver and decline mechanics
- **[bates-numbering.md](bates-numbering.md)** — the `<FIRM>-<MATTER>-<6-digit>` prefix scheme, continuous numbering, privilege-log reserved-Bates format, production indexes
- **[retention.md](retention.md)** — 7-year baseline, special retention by type, client file vs attorney file, malpractice-margin reasoning, destruction with partner approval

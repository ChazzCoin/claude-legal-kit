# Alabama state

The Alabama state-court jurisdiction module — and the kit's worked example of a jurisdiction folder. A firm in another state copies this folder's shape and replaces the content.

## Contents

- `deadlines.md` — Alabama time computation, statutes of limitations, pre-suit notice deadlines, and procedural response deadlines.

## Planned

- `rules/` — Alabama-specific procedural and local rules.
- `templates/` — Alabama caption formats and certificate-of-service language.
- `filing/` — AlaFile e-filing portal quirks, page limits, accepted formats.

These fill in as matters need them.

# Alabama state — deadlines

Deadline rules for Alabama state court. The firm-level method is in `firm/practice-kit/shared-library/rules/deadlines.md`; this file supplies the Alabama numbers.

**Verify each against the current Alabama Code and Rules — these are working defaults, not a substitute for checking.**

## Time computation — Ala. R. Civ. P. 6

- The day of the act is **not** counted; the last day **is** counted.
- Saturdays, Sundays, and legal holidays at the end of a period extend it to the next business day.
- Periods under 7 days — exclude intermediate Saturdays, Sundays, and legal holidays.
- Periods of 7 days or more — intermediate weekends and holidays count.
- Service by mail — add **3 days** (Ala. R. Civ. P. 6(e)).
- Service in person, by fax, or by email to a designated address — no days added.

## Statutes of limitations — common claims

| Claim type | SOL | Statute |
|---|---|---|
| Personal injury (general negligence) | 2 years | Ala. Code §6-2-38(l) |
| Medical malpractice | 2 years from accrual, **4-year cap** | Ala. Code §6-5-482 |
| Med-mal — discovery rule | up to 6 months from reasonable discovery | Ala. Code §6-5-482 |
| Wrongful death | **2 years from death** | Ala. Code §6-5-410 |
| Auto accident (PI) | 2 years | Ala. Code §6-2-38(l) |
| Product liability (PI) | 2 years; **statute of repose: 10 years from sale** | Ala. Code §6-5-502 |
| Premises liability | 2 years | Ala. Code §6-2-38(l) |
| Workers' compensation (initial claim) | 2 years from accident | Ala. Code §25-5-80 |
| Fraud | 2 years from discovery; 6-year cap from event | Ala. Code §6-2-3 |
| Breach of written contract | 6 years | Ala. Code §6-2-34(9) |
| Breach of oral contract | 6 years | Ala. Code §6-2-34(9) |
| Slander / libel | 2 years | Ala. Code §6-2-38(l) |

## Pre-suit notice deadlines

**Critical.** Many Alabama claims require pre-suit notice; missing one can be fatal to the claim.

| Claim against | Notice deadline | Statute |
|---|---|---|
| City / municipal corporation | **6 months** from injury | Ala. Code §11-47-23 |
| County | **12 months** from injury | Ala. Code §11-12-8 |
| State (Board of Adjustment) | Per Board procedures | Ala. Code §41-9-60 et seq. |
| Med-mal (expert review affidavit accompanies the filing) | Filed with complaint | Ala. Code §6-5-551 |
| Workers' comp — oral notice to employer | **5 days** from accident | Ala. Code §25-5-78 |
| Workers' comp — written notice | **90 days** from accident | Ala. Code §25-5-78 |

## Procedural deadlines — most common

| Event | Deadline | Rule |
|---|---|---|
| Answer to complaint | 30 days after service | Ala. R. Civ. P. 12(a) |
| Response to interrogatories | 30 days after service | Ala. R. Civ. P. 33(a) |
| Response to RFPs | 30 days after service | Ala. R. Civ. P. 34(b)(2) |
| Response to RFAs | 30 days after service | Ala. R. Civ. P. 36(a) |
| Motion for new trial | 30 days after entry of judgment | Ala. R. Civ. P. 59(b) |
| Notice of appeal | 42 days after entry of judgment | Ala. R. App. P. 4(a) |

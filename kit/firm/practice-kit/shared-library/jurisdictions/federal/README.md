# Federal

The U.S. federal jurisdiction module — the Federal Rules of Civil Procedure, which apply in every federal district. A specific district's **local rules** get their own jurisdiction folder (e.g. a `federal-<district>/` module) that builds on this one.

## Contents

- `deadlines.md` — federal time computation (FRCP 6) and the common procedural response deadlines.
